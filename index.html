Export all your AI chats

Works with Claude and ChatGPT. Everything runs in your own browser. Your chats go straight from the chat site to your computer or your own Google Drive, and nobody else sees them.

0Choose where your chats should go

1Drag the button to your bookmarks bar

If you can't see the bookmarks bar, press Ctrl/⌘ + Shift + B. If you switch the option above, drag the button again, because each option has its own button.

⇣ Export my chats

2Click it on claude.ai or chatgpt.com

Open claude.ai or chatgpt.com while logged in and click the bookmark. A small box in the corner shows the progress. When it's done, a .txt file appears in your Downloads.

Open claude.ai or chatgpt.com while logged in and click the bookmark. It reads your chats and sends them to this page in a new tab. If your browser blocks that, it downloads a file instead, and you drop that file here.

3Create your Google Doc

Google Docs allow up to 100 tabs per document, so large archives are split into several docs (Part 1, Part 2, …). Google also limits how fast documents can be written, to about 30 chats per minute. Keep this tab open until it's finished. This page asks only for permission to create files in your Drive. It can't see any of your other files.

Privacy policy · Source code on GitHub

Only each chat's current version is exported. If you edited a message, only the latest branch is included. Attachments are listed by name, without their contents. If a chat site changes how it works, the button may stop working until it's updated.
